# Cozybat — site vitrine

Site statique. Aucune compilation, aucune dépendance à installer.

## Contenu
- `index.html` — page d'accueil
- `realisations.html` — galerie des chantiers
- `chantier.html` — fiche chantier (`chantier.html?id=...`)
- `admin.html` — back-office de gestion des chantiers (non lié depuis le site public)
- `assets/` — logos et photos
- `support.js`, `image-slot.js`, `chantiers.js` — scripts

## Mise en ligne
Déposez le contenu de ce dossier à la racine de l'hébergement. Compatible Netlify, Vercel, GitHub Pages, Cloudflare Pages ou un simple FTP.

- **Netlify / Cloudflare Pages** : glissez-déposez le dossier dans l'interface.
- **GitHub Pages** : poussez le dossier à la racine du dépôt, puis activez Pages sur la branche `main`.
- **FTP** : uploadez tout le dossier dans `www/` ou `public_html/`.

Les polices (Archivo, IBM Plex Mono) sont chargées depuis Google Fonts : une connexion internet est requise à l'affichage.

## Avant mise en production
Les coordonnées, chiffres et témoignages sont des textes de démonstration. Remplacez-les avant publication.
